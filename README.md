# To-Do-List - React

A simple, fast and responsive To-Do List app built with React. Add your daily tasks, delete them, and reorder them with Up / Down buttons.

**Live Demo:** https://to-do-list-ms-ufyan10.vercel.app/

### ✨ Features

- ➕ Add new tasks
- ❌ Delete tasks (Red button)
- ⬆️⬇️ Move tasks Up / Down to reorder priority
- 💾 Tasks managed with React useState
- 📱 Fully responsive - works on mobile & desktop
- Clean & minimal UI

### 🛠️ Tech Stack

- **React.js (Vite)**
- **JavaScript (ES6+)**
- **CSS3** - Flexbox & responsive layout
- **Vercel** - Deployment
